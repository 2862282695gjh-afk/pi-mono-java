LocalAgentBackend 设计草图

补「派生自己 runtime 的子 agent」—— CampusClaw 自派生路径

现状:SubAgentBackend 只有 3 个实现,全是连外部 runtime(ACP 进程 / HTTP / A2A),spawn_agent 从不在进程内 new Agent()。本设计新增第 4 种 backend —— LocalAgentBackend:open() 时本机 new Agent()(独立 AgentState/cwd),子 agent 跑在 CampusClaw 自己的 AgentLoop 上。

★ 新增 现有(复用) 现有外部 backend(对比)

新增 4 个类:
  • LocalAgentBackend —— 实现 SubAgentBackend,open() 时 new Agent();和现有 3 个 backend 平级,只是执行面在进程内。
  • SpawnGovernor —— 自派生比外部 spawn 更易失控(同进程递归),强制的并发/深度/每父子数闸门(对齐 OpenClaw maxConcurrent/maxSpawnDepth/maxChildrenPerAgent)。
  • AgentEventMapper —— 把子 Agent 的 AgentEvent 映射成 backend 契约的 SubAgentEvent(ACP 那边是 AcpEventMapper 反过来做,这里正向)。
  • AgentFactory —— 按 OpenRequest(model/thinking/cwd override)造一个隔离的子 Agent(独立 AgentState、独立 workspace、可选缩小的 tools/prompt)。

关键边界:自派生路径(local)全程不离开进程——从 SpawnAgentTool 到子 Agent 都在主 runtime 同一 JVM 里,只靠 SpawnGovernor 做隔离与限流。外部 backend(虚线)则各自出进程。两条路径对 SpawnAgentTool/registry 透明,只是 backendId 不同。

③ 自派生时序 — 一次 spawn_agent(local)

图 C · open / prompt / close 全流程
sequenceDiagram
    participant T as SpawnAgentTool
    participant L as LocalAgentBackend
    participant G as SpawnGovernor
    participant F as AgentFactory
    participant C as 子 Agent (AgentLoop)
    participant M as AgentEventMapper

    T->>L: open(OpenRequest{parent,cwd,model,depth})
    L->>G: acquire(parentId, depth)
    alt 超限
        G-->>L: reject
        L-->>T: SubAgentException(SPAWN_LIMIT)
    else 放行
        G-->>L: granted
        L->>F: create(OpenRequest)
        F->>C: new Agent(独立 State/cwd)
        L-->>T: SubAgentSession
    end

    T->>L: prompt(session, task, signal)
    L->>C: agent.prompt(task)
    loop 子 agent 自己的 runInternal
        C->>M: AgentEvent
        M->>M: map → SubAgentEvent
        M-->>L: SubAgentEvent
        L-->>T: Flux 推流
    end
    C-->>L: run 结束

    T->>L: close(session, "tool-finished")
    L->>G: release(session)
    L->>C: tear down / 可选归档
隔离 vs 外部 backend:子 Agent 与主 Agent 共享同一 JVM 的 LLM provider / 文件系统 / 虚拟线程,隔离边界比「外部进程」弱——这正是 SpawnGovernor 必须存在的原因(OpenClaw 同 runtime 内 spawn 也因此配一堆 limit)。cwd 隔离 + 可选 tools/prompt 缩小是软隔离,真正硬上限靠 governor。

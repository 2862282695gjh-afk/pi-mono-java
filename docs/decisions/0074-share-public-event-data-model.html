ADR-0074：公共事件数据模型

Status: Accepted · Date: 2026-09-08 · Version: 1.1.0

Context

设计仓 2ee2a321 已确认 POST 完整帧与 GET 历史共享事件对象。 Java 基线 2f52e9b8 的 RuntimeEntryCodec 与 RuntimeSseEventVO 仍实现旧入口，内部记录包含不应公开的恢复信息。

Decision

新增内部 CommittedEventDTO、公共 SessionEventResponseVO 及关闭的 11 类事件集合。 公共业务字段使用类型化响应 VO 并展开到根对象；事件序号和分支锚点只保留在 DTO。 工具结果显式使用 isError 属性；可选字段按已确认契约省略。常量集中在 common，不新增 Maven 依赖。

选项与取舍

  • 采用 DTO 与 VO 分离：可独立管理数据库排序和客户端字段，代价是后续需要显式投影。
  • 直接返回内部 Entry 会耦合上下文存储并暴露私有结构，因此不采用。
  • 全部响应使用任意 Map 虽代码较少，但无法在类型层面约束不同事件的业务字段，因此仅工具 arguments 保留业务 JSON 对象。

Consequences

本片建立数据对象与序列化边界，尚未切换 HTTP。公共投影验证完整字段并冻结集合，原始私有内容不得进入公共表； 公共事件组合持久化已由同一 Spring 事务实现；整数分页、SSE 和跨实例控制继续由各自实施片接入。pi 的内核通知不提供本项目 HTTP 契约，这属于架构变更。

原子写入与形成时间

Entry、内部 Record/Usage 和关联公共事件共享同一 Session 事务与序号分配器，任一步失败均回滚。 形成时间写入前归一到 UTC 毫秒并回填 DTO，避免数据库毫秒四舍五入造成 POST/GET 差异。公共表只保存安全业务字段，不增加 Maven 依赖。

Validation

独立 JSON 序列化测试覆盖工具成功/失败布尔字段、delta 省略规则和根对象展开。 完整验证命令与企业编译缺口见关联设计。

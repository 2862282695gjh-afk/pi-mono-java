# ADR-0110：统一开发设置与逐题 Plan 交互

Status：Accepted。Date：2026-09-16。

## Context

源码基线 `1d08f98eb04f8ea6e01bcfbfd4008c1b638391c4` 的 IP/Headers 仅在页面内存，配置来自启动环境，侧栏和模式菜单受滚动祖先裁切；问题卡同时呈现所有问题并重复展示工具 JSON。有效设计基线为设计仓 `3e3d569`。

## Decision

- 统一开发者设置。浏览器按实际后端与认证 IP 保存 Header；本地服务保存登录账号密码，读取只返回配置状态。草稿与已应用快照分离，保存后新请求生效。
- 代理转发检查页面确认的配置版本，环境切换清理视图和 ETag，旧请求不能转入新目标。成功 Token 与立即清空是独立显式动作，不隐式提交其他设置。
- 采用根浮层和独立时间线/Composer 布局。三点菜单提供删除，绑定被点击的会话；结果未知只读核对。
- 模式显示 Build/Plan；当前只呈现一题，前后导航保存本地草稿，末题一次提交全部答案。提问工具调用/结果保留在模型与历史，默认 UI 由问题卡吸收。
- 工具参数及 JSON 结果采用有预算的结构展示与原文回退。普通结束已有回答时不重复显示完成通知；计划回答、计划批准与工具授权各自独立。

## Options 与取舍

继续编辑环境文件无需本地配置服务，但仍要求重启和反复切换入口；选择已知字段的运行时配置，代价是版本与双端保存失败处理。把所有秘密放入浏览器更简单，却扩大密码暴露面；账号密码保持本地服务权威，Header 按产品要求在浏览器保存并默认遮蔽。

逐题 HTTP 提交会引入新的等待及部分回答协议；采用客户端分页加整批提交，复用既有事务和根执行。提高 z-index 无法逃出 overflow 裁切，因此采用 Teleport 浮层并维护边界定位、焦点和监听清理。

## Consequences

刷新可恢复已保存配置，问题阅读量降低，菜单操作与当前选择解耦。代价是本机保存数据、配置代次、页内问题位置和浮层生命周期的维护。浏览器存储不是加密凭据库；设置仅装配到受控开发工作台。代码 HMR 沿用 Vite，启动参数、依赖和 CA 更新仍需重启。未发送草稿跨整页刷新不在承诺内。

不新增 npm/Maven 依赖、数据库表或公共 Runtime API。提示词式 Plan 仍非强制只读沙箱；真实认证和模型遵循率单独验收。

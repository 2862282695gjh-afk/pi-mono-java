Context

既有 Thinking PUT 在锁外检查模型能力并生成事件，由锁内相同版本保护。Command 不提供版本， 因此仅把 expectedVersion 设为可空会使锁前通过的能力检查在并发 Model 提交后失效，或者记录过时的 previousThinking。

Java 源根：modules/coding-agent-cli/src/main/java/com/campusclaw/codingagent/runtimeapi/。 基线证据：session/RuntimeSessionConfigurationService.java:changeThinking/requireThinkingSupported、 persistence/MyBatisRuntimeSessionRepository.java:updateThinking。 model/MateRuntimeModelManager.java:resolveModel 和 model/CatalogRuntimeModelManager.java:resolveModel 当前都读取本地目录/配置，无远端请求。

选项与取舍

  • 锁前验证后直接无版本写入：简单，但能力和旧值可能失效，不采用。
  • 复制 Command 专用事务或不断乐观重试：增加第二套配置语义或重试路径，不采用。
  • 共享 Repository，分开本地 admission 与 entryFactory：参数增加，但能力和事件均消费同一锁内状态，采用。

Decision 与理由

  • SessionThinkingConfigurationService 负责精确 on/off、查询、能力检查与领域事件构造； Contributor 只绑定元数据、独立准入和 Handler，无中央名称 switch。
  • 复用既有行锁事务。锁内先存在/可选版本/idle，再本地能力、同值、事件工厂。 同值仍检查开启能力，但不调用工厂、不分配 ID/序号、不升版本。
  • Agent 目录快照只在锁外取得。开启保留预检查，锁内用最新 modelId 复核； resolveModel 明确只读本地配置，不刷新 Agent、不远端调用、不取请求凭据。关闭与查询不依赖能力服务。
  • 既有 PUT 保留请求 VO、强 If-Match、428/412、新 ETag 及原错误转换；Model/运行前校准不改契约。
  • 实际变化追加一条 session.thinking.changed；sourceEventSeq 来自实际 Entry 序号，查询/同值为 null。 DTO 只传数据，公共响应 VO 和共享 HTTP 留待后续切片。

pi 4af9d21d3b4d664e4a29fcabfec85171077248e3： packages/coding-agent/src/core/agent-session.ts:setThinkingLevel 按能力 clamp，实际变化才追加； packages/coding-agent/src/core/session-manager.ts:appendThinkingLevelChange 以当前 leaf 为父节点。 Java boolean、idle、能力不足时报错是产品约束；数据库锁内复核与内部领域序号是架构差异，不是 pi 现有 HTTP 行为。

Consequences

  • 正面：Model/Thinking 并发遵循行锁提交次序，不支持模型不能被开启 Thinking；同值无持久化副作用。
  • 代价：开启进行预检查和锁内检查，本地 Model Manager 必须保持短小且不能发展成远端调用。
  • 范围：不改设计仓、不加升级 SQL、不发布 Command HTTP；Builtin/Skill 共享入口仍需统一验收。 本 PR 合并后才推进 Compact Runtime，不同时打开下一待审切片。

验证与边界

27 项 Thinking 组合测试、1552 项模块/依赖测试及完整 mvnw verify 通过； 24 项真实 openGauss Repository IT 通过，覆盖相同命令竞争、模型先提交后的能力拒绝、事务/序号回滚及重启查询。 数据库并发为单 JVM 多连接，不冒充最终跨 JVM HTTP 验收。质量脚本原路径缺失，归档副本 0 errors/20 项旧命名 warnings。

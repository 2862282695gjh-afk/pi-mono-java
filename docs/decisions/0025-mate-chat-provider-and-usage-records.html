Accepted ADR-0025 · 2026-08-25

采用 Mate Chat 通用 Provider 与独立 Usage Record

决策范围：CampusClaw 模型调用、CampusMate 透明代理、Runtime Usage 持久化。

上下文

规范仓 2.0.0 已将 OpenAI Responses 方案替换为前台 Chat SSE： POST /mate-service/v1/LLM/chat。CampusClaw→CampusMate 处于内部网关信任边界， 不携带应用凭据；CampusMate 托管上游路由和秘密。

实施前 Java 主线按 Api 路由 Provider，不能区分使用相同 API 的不同 Provider； Runtime 还把生命周期 Usage 放入物化 Session JSON，不符合 pi 的 Record + Stats 模型。

决策

  • 增加 ProviderId、ProviderAuth.none() 和 AiProviderRegistry；完整 Provider 身份优先于旧 ApiProviderRegistry。
  • 注册唯一 Provider mate-model-manager，内部 API 固定为可配置的 openai-completions。
  • Provider 将 AgentLoop Context 转换为严格 Chat JSON；首版只接受文本和 function tool。
  • CampusMate 替换公开模型 ID、注入私有凭据，并逐字节转发成功 SSE；响应 chunk 不重写。
  • 取消通过关闭 HTTP/SSE 完成；不提供远程 cancel operation，不自动重放结果未知的创建请求。
  • 新增 t_session_records 与 t_session_stats；Assistant/Compaction Entry、Usage Record 和 Stats 在一个数据库事务中提交。
  • 删除公开 Session 的 lifetimeUsage 和 Entry/SSE 的 usage；上游缺失 usage 时写全零内部记录。

接口与身份边界

项目冻结值
Providermate-model-manager
APIopenai-completions，只用于 CampusClaw 内部选择实现
Endpointcampusmate.base-url + campusmate.endpoints.model-chat-path；共享配置由 ADR-0026 约束
认证CampusClaw→CampusMate 为 ProviderAuth.none()；CampusMate→上游由 Mate 注入私有凭据
取消关闭 subscription 和 HTTP/SSE，结果为 StopReason.ABORTED

Usage 事务不变量

  • Entry 与 Record 共用 t_session_sequences；公开 Entry 序号允许有间隔。
  • Record 固定 lane=main，保存 cause/entryId/attempt/stopReason/usage。
  • Record 不设置 parent，不更新 active_leaf_id，不进入公开 SSE 或分支查询。
  • cached_tokens += cacheRead；uncached_tokens += input + cacheWrite； total_tokens += totalTokens；cost_total += cost.total。

明确不做

  • 不实现尚未冻结的 Model Manager 模型目录、Agent 模型列表和模型解析接口。
  • 不把工具发现、工具凭据链或工具 HTTP 客户端复制到模型 Provider。
  • 不支持图片、音频、文件、Tool 图片结果、远程取消或创建请求自动重试。
  • 不在 CampusClaw 中保存上游 API Key、endpoint 或私有模型 ID。

依据与后果

pi-mono 基线：5cd93f688aaab89dbb6dfa4aca535f21796ae185； Java 实施前主线：0d7a12e1dd89eed52f6e12db717fd5703b6b2125； Mate 实施前主线：6d5e6f3714e1cf8744d187a4796ca06300ad7e33。

正面后果：Provider 身份不会因共享 API 冲突；上游秘密集中托管；reasoning 和 ToolCall 可续轮； Usage 不污染消息分支。代价：Chat SSE 解析与数据库表增加，公开 Session 不再直接返回生命周期 Usage； 如未来需要统计查询，应单独冻结接口。

完整实现设计见 Mate Chat 通用 Provider 2.0 实现设计； CampusMate 单一服务地址与 Endpoint 目录见 ADR-0026。

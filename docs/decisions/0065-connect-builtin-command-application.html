ADR-0065：接通 Builtin 执行应用

Status：Accepted · Date：2026-09-07 · Version：1.0.0

实现基线 53496bbec9d8368b19e3b9a03030eed7ce15c182；只读设计 88f4df16bc24bbfcd28e1ec374feb2de0db8be3b，Builtin 2.9.0 / Slash 1.6.0 / 操作13。

交付前正常合并 #240 的 main 18bf7026d75cf28a9652025eaa19800eb36c4c64； 组合提交 4291dd8d6e6bde63a08819379bb8d97450f7859f 无冲突，不修改 Registry 或堆叠未合入分支。

Context

七个内部 Builtin 与业务投影已合入，但应用层尚未把一次请求的定义选择、准入、调用及结果连接起来。 共享 GET 完整缓存切片独立开发；POST Builtin 可使用 main 已有的来源过滤入口，不应为并行引入占位路由或未合入依赖。

Options

  • 在 Controller 按 name 分派七个窄服务：混合 Web 与执行职责，并丢失 Definition 的扩展边界；不采用。
  • 用 Builtin 正则作为共享 POST 的全局请求约束：会错误拒绝 Skill 类别；不采用。
  • 显式 Builtin 应用入口，使用已有 Registry 与独立响应组装器：职责完整、无未合入依赖；采用。

Decision

  • CommandExecutionService.executeBuiltin 只消费已选定 Builtin 类别的 VO；未来共享入口独立选择请求类型。
  • VO 声明标准 Jakarta 约束，Service 验证自己的归一副本，缺省只在 Service 应用；严格 JSON 类型与未知字段沿既有 VO 模式拒绝。
  • 一次 Catalog 固定 Definition 身份，预览准入后委托 Handler；业务参数与事务/操作锁内复核保持原职责。
  • 只有 CommandResponseAssembler 按结果类型分派。复用 RuntimeSessionView 携带业务 VO 与可选 ETag，不作为公开 result 包装序列化。
  • 完整 Session/ETag 同取 Handler 的权威 DTO；不从旧 Catalog 拼字段、不在投影中重新查数据库。
  • 请求级 Compact 能力用 try-with-resources 清理，关闭或取消派生完成视图不取消已接受执行。
  • 统一稳定错误白名单并移除敏感 cause，不将 PUT 专属错误或第三方信息泄漏给 Command 调用方。

Consequences

  • 正面：新的 Contributor 无需修改中央命令名分派；请求、结果及凭据生命周期均有可测试的应用边界。
  • 代价：通用完成结果需要组装器维护受支持 DTO 白名单；未知或空结果失败关闭，不直接序列化。
  • 约束：现有 Service 返回载体现在用于 Session 相关业务 VO；只有完整 Session 结果带 ETag，Web 不序列化载体本身。
  • 后续：共享类别识别、Header、HTTP 状态/ResultBean、虚拟请求线程等待及跨进程验收仍由最终 HTTP 切片完成。
  • 范围：不修改设计仓、GET Catalog 新接口、Runtime 生命周期、数据库表、升级脚本或 Skill 未决协议。

Validation

验证包含严格输入、单次来源解析、Definition 身份、准入拒绝、七个真实 Contributor 的应用接通、业务投影/ETag同源、 错误白名单、请求作用域及取消隔离。测试的外部业务数据由 mock 控制，不称作真实数据库或 HTTP 验收。 具体提交/测试数/预算见 PR 交付记录；公司 NativeParent 不可用时明确报告公司编译未验证。

ADR-0089：持久化受管 Agent 工具权限快照

Status: Accepted · Date: 2026-09-08 · Version: 1.0.0

Context

Java分析基线80ca6cc96d35fef2aa86bbd032a980945db4ecbd已从Mate取得Agent与Skill的bindingTools，但AgentRuntimeManager写入和读取受管目录时丢弃该字段。首次准备后重新加载、缓存命中和进程重启都会失去ASK等可信权限元数据。pi基线4af9d21d3b4d664e4a29fcabfec85171077248e3没有对应的受管权限缓存；本决策属于Java目标运行目录的安全加固。

Decision 与选项

settings.json保存Agent级bindingTools，每个skill.json保存Skill级bindingTools，读取时恢复完整BoundTool。新快照必须显式写数组；[]表示已确认没有绑定，缺少字段表示旧快照没有可信权限记录并使整个快照无效。

保留schemaVersion=1，由必需字段完整性门禁识别旧缓存。prepareCached只返回空结果且不访问Mate；prepare沿既有冷加载路径重新获取并原子发布。没有选择把缺字段默认为空，因为这会混淆未知权限与合法无绑定；也没有保存工具调用定义和参数Schema，它们仍由Mate实时发现。

权限值的解释不在缓存层改变：ASK需要明确可信值，未知值、冲突或缺少可信绑定仍为DENY。缓存层只保证原始绑定记录跨发布和重启保持一致。

Consequences

正面：确认策略获得稳定的Agent与Skill权限输入，重启不再改变执行边界；旧缓存不会以半完整状态命中。代价：旧目录在下一次prepare时需要Mate可用才能重建，每个绑定会增加少量JSON存储。目录版本保持不变，运维判断必须同时检查必需字段，不能只看版本号。没有新增Maven依赖。

Validation

实现提交2b76bbf9在最新main基线独立编译。AgentRuntimeManagerTest精确比较完整Agent与Skill BoundTool，覆盖首次发布、同进程缓存命中和全新Manager重启读取；另覆盖缺字段只读拒绝、允许联网时重建。HTTP进程夹具显式写空数组，证明合法无绑定缓存仍可加载。聚焦51个测试以及Spotless、Checkstyle和diff检查通过。

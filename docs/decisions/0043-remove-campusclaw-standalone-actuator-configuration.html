ADR-0043：删除 CampusClaw 独立服务的 Actuator 专用配置

Context

修改前，公司镜像以子模块集成前提运行，在应用配置中关闭管理端口、默认禁用 Endpoint，并排除 18 个 Actuator 自动配置。ADR-0038 和 ADR-0040 分别记录了这一边界的初始关闭方案和排除清单收敛方案。

CampusClaw 在公司中现已是独立服务。原配置所针对的上层子模块集成前提不再成立，应用不应继续隐式抵消公司运行平台或父 POM 提供的标准 Actuator 行为。

Decision drivers

  • 让独立服务的管理策略由公司运行平台明确管理。
  • 删除与 18 个 Spring Boot 自动配置类名的长期耦合。
  • 保持 CampusClaw 业务 HTTP/SSE、数据库、CampusMate 和日志契约不变。
  • 不保留已失效部署拓扑的兼容键或部分排除。

Considered options

保留全部现有配置

优点：不改变当前管理面行为。
缺点：独立服务仍携带已失效的子模块集成策略，并持续耦合 Spring Boot 类名。拒绝。

只删除 management.* 或只删除排除清单

优点：变更行数较少。
缺点：仍保留一半旧策略，无法形成清晰的独立服务边界。拒绝。

删除全部 Actuator 专用应用配置

优点：应用不再覆盖平台策略，配置边界与独立服务拓扑一致。
缺点：如果最终 Classpath 包含 Actuator，其实际暴露需在公司运行环境重新验证。接受。

Decision

  • 从 campusclaw/src/main/resources/application.properties 删除 management.server.port 和 management.endpoints.enabled-by-default。
  • 删除仅由 18 个 Actuator 类名组成的 spring.autoconfigure.exclude 清单。
  • 不在应用配置中保留旧键、空值、注释或兼容排除。
  • 保留 server.* 业务端口和其他所有业务配置。
  • 删除专有测试中的 Actuator 断言，并将剩余 CampusMate 配置测试重命名。

Intentional difference

部署架构变化：CampusClaw 从需要抵消上层管理面的子模块集成边界收敛为公司独立服务。公司集成边界：Actuator 的存在、端口和暴露由有效公司 Classpath 与运行配置决定。

Consequences

  • 正面：应用配置不再维护易随 Spring Boot 升级漂移的 Actuator 类名清单。
  • 正面：管理面行为与公司独立服务的标准运行策略一致。
  • 边界：本仓库不再保证管理端口为 -1 或 Endpoint 默认关闭。
  • 门禁：公司 Maven 和运行环境必须验证最终 Actuator 依赖、端口和暴露范围。

Validation

  • 扫描镜像配置，确认不存在 management.*、Actuator 自动配置类名或专用排除。
  • 执行保留的 CampusMate 配置测试、根 Reactor verify 与镜像同步 dry-run。
  • 在可解析 NativeParent 的公司 Maven 环境执行镜像 clean verify 和启动验证。
  • 生成并验证 PlantUML/SVG，执行文档链接、Mermaid 禁用和 Git diff 检查。

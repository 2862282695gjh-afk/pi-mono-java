Context

变更前，根 POM 以 spring-boot.version=3.4.1 同时管理 Spring Boot BOM 和 Maven 打包插件，Reactor 模块与公司镜像共享该版本源。上游 3.4.5 在同一维护线内提供缺陷与依赖修复，并修复影响 3.4.0–3.4.4 的 CVE-2025-22235。

仓库没有 Spring Security 或 EndpointRequest.to() 的使用，因此没有观察到该漏洞的应用触发路径。本决策是依赖维护与安全修复，不改变系统架构。

后续变化：CampusClaw 转为公司独立服务后，ADR-0043 删除了当时保留的 Actuator 应用配置。该部署架构变化不改写本 ADR 的补丁升级结论。

Decision drivers

  • 移除受已公开安全公告影响的 Spring Boot 版本。
  • 获取 Spring Framework、Tomcat、Reactor、Netty、Jackson 和 JDBC 的维护修复。
  • 保持 Spring Boot 3.4 维护线，不扩大到次要版本迁移。
  • 保持 BOM、打包插件、子模块和公司镜像的版本一致。

Considered options

保留 3.4.1

优点：零变更。
缺点：继续使用受 CVE-2025-22235 影响的上游版本，并丢失后续补丁修复。拒绝。

升级到 3.4.5

优点：在同一维护线内获得安全、框架和传递依赖修复，完整构建可验证兼容性。
缺点：传递更新多个底层库，仍需公司父 POM 环境的启动复验。接受。

跨越到更新的 Spring Boot 次要版本

优点：可获得更新功能与更长的版本时间线。
缺点：引入超出本次目标的迁移行为和测试面。拒绝。

Decision

  • 将根 POM 的 spring-boot.version 从 3.4.1 更改为 3.4.5。
  • 不为子模块或公司镜像建立版本覆盖，BOM 与打包插件继续共享一个属性。
  • 不同时升级仓库显式锁定的 MyBatis、JobRunr 或 LLM SDK。
  • 保持公司 Actuator 排除清单不变；其中三个历史字符串的非精确匹配是既有风险，不与补丁升级混改。

Intentional difference

安全修复：不再使用受 CVE-2025-22235 影响的 3.4.1 版本。产品约束：JDK 21、HTTP/SSE 契约、数据库配置和工具集保持不变。架构变更：无。

Consequences

  • 正面：Spring Boot、Spring Framework、Tomcat、Reactor、Netty 等组件获得补丁级更新。
  • 正面：主 Reactor 585 个测试和公司镜像 1292 个测试全部通过，无 Java 或配置适配。
  • 负面：多个传递依赖同时变化，回归范围必须包含主服务和公司镜像。
  • 边界：公司父 POM 和最终 Actuator Classpath 不在本仓库，归并前应在公司工程复验启动。

Validation

  • 对比 3.4.1 和 3.4.5 的 Maven 有效依赖树。
  • 对比两个版本的 Actuator 自动配置类清单。
  • 执行主 Reactor 完整 verify 和公司镜像完整 verify。
  • 执行镜像同步 dry-run、文档链接与格式校验、git diff --check。

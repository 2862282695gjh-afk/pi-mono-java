ADR-0060：Builtin 传递完整权威 Session

Status：Accepted · Date：2026-09-07 · Version：1.1.0

设计依据：pi-mono-java-design@88f4df16bc24bbfcd28e1ec374feb2de0db8be3b， 04-命令与技能/01-内置命令/README.md 2.9.0 §8/8.1；设计仓只读。 Java 变更前基线：6f52fddc87a03c20916fc7b6ef1de87f6a7a8cf5； 本轮实现：b2506c1f2b2fcb36228d4114cd32f77c15c42ab0。

Context

Slash 成功结果改为复用业务资源。已有 Model/Thinking Repository 返回完整 Session， 命令窄服务却只保留标量；Name 事务结果也只保留名称；Status 读取的是 Catalog 子集。 在提交后重新 GET 补资源，会把其他并发提交混入本次结果。

源码根 modules/coding-agent-cli/src/main/java/com/campusclaw/codingagent/runtimeapi/： service/command/{SessionNamingService,SessionModelConfigurationService,SessionThinkingConfigurationService}.java:execute、 service/command/readonly/RuntimeSessionStatusService.java:query、 persistence/MyBatisRuntimeSessionRepository.java:updateName/updateModel/updateThinking 与 session/RuntimeSessionResponseAssembler.java:getView。

考虑过的选项及取舍

  • 提交后 GET：调用简单，但可能读到并发新版本，不采用。
  • 用旧 Catalog 拼接字段：少一次查询，但会产生新旧字段混合资源，不采用。
  • 每个命令维护完整资源副本和响应 VO：调用局部化，但复制字段和投影规则，不采用。
  • 共用完整 Session 结果：携带的内部数据更多，但可复用已有资源与 ETag 投影，采用。

Decision 与理由

  • SessionCommandResultDTO 原样携带一次查询或锁内提交结果；changed/sourceEventSeq 只供内部使用。
  • Status/Name/Thinking 查询及 Name/Model/Thinking 修改或同值统一走该结果；Model 查询独立返回模型清单。
  • Name 同值保留原对象；更新后同步锁内对象的名称、版本和时间，不改状态、leaf 或历史。
  • 配置更新写入时间与返回时间统一为数据库 TIMESTAMPTZ(3) 毫秒精度，避免修改结果与查询结果不同。
  • 后续应用层仅按结果类型投影：Session 委派已有 Assembler，Models 使用已有业务 VO。 公开成功结果禁止 command/changed/sourceEventSeq，不增加替代回执，不新建七种 Command VO。
  • 保留 PUT 的 If-Match/ETag、事务准入、同值不写和领域 Entry；不新增对实时 state/usage 的 ETag 缓存承诺。

业务资源复用和结果分型属于 Java 架构变更，删除公开回执属于产品约束。 本轮以既有 Java API 为主基线，不把新 HTTP 或数据库事务行为表述为 pi 已有能力。

Consequences

  • 正面：正文与 ETag 同源；新增 Session 字段可沿同一结果通道传递，无需逐命令复制。
  • 代价：Status 增加一次完整查询；内部结果含持久化字段，应用层必须白名单投影，不能直接序列化。
  • 组合：R07 已随 main b143aec605ca444f8af62ce47034004446cc2e33 合入，本分支普通合并提交 ab88af5335f40bb371736bc0f143328d3eb7caf1 保留锁后 Usage 读取、完整结果及毫秒精度。 随后普通合并含 #235 的 main 188b1c3fd22fe9a943391f313a677d40da7530fd， 组合代码提交为 9dcd938fdde1daafc221a97e24b5de438991d379，无额外生产修改。 CommandResponseAssembler/HTTP 尚未发布，不能把内部测试视为完整公开契约验收。
  • 范围：不新增 Maven 依赖、升级 SQL、Events V2、旧控制接口迁移或 Skill 待决执行契约。

验证

精确代码提交、测试和未验证项统一维护在关联实现说明。重点验证变化/同值完整对象、 不提交后重读、实际 Session/ETag 投影、真实 openGauss 并发与时间精度，以及原条件 PUT 回归。

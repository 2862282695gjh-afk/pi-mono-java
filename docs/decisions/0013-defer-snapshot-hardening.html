ADR-0013 · 暂缓托管 Agent 快照九条防篡改校验

Status: Superseded · Date: 2026-08-17 · Amended: 2026-08-24 · Replaced by: ADR-0022 · 设计文档: agent-skill-runtime · 部分暂缓: ADR-0011 · 原登记条目 DEF-008 已因目录契约替换而关闭

Context

ADR-0011 为本地优先加载选定了 fail closed 语义，实现中据此落地了九条快照防篡改/防漂移规则（路径穿越、符号链接、完整性比对、响应形状校验、资源白名单、SKILL.md 可重建比对、原子发布、物化后复验、元数据最后写入），约 290 行主代码 + 约 800 行测试，占 PR #131 modules 部分约 22%。评审反馈 PR 体量过大（5000+ 行），且其中安全加固在当前阶段（本地 CLI 试点、单信任域 CampusMate）收益有限。

Options considered

  • 保留全部九条规则
    Pro：安全边界完整，与 ADR-0011 语义一致。
    Con：PR 体量与评审成本维持现状。Rejected（评审明确要求缩减）。
  • 按部署形态裁剪（保留穿越/白名单，删其余）
    Pro：保留最关键的远程攻击面防线。
    Con：规则间共享校验方法与测试基建，部分裁剪的拆分成本接近全量保留。Rejected。
  • 整体暂缓九条规则，语义降级为"无法加载即重新物化"
    Pro：净减约 1100 行（主代码 659→341，测试 25→12）；快照损坏/中断场景由重新物化自愈，功能等价；规则可从 git 历史（本 ADR 前一个提交）整体恢复。
    Con：接受已知风险窗口（见 Consequences）。Chosen。

选择理由：该物化器当前只用于显式托管 CLI 流程；公共 HTTP V1 只读 Manager 预置的 agent/{agent_id}/.campusclaw/ HTTP 文件契约，不调用本物化器。恢复条件见 DEF-008；降级语义保持"本地优先 + 按需物化"的架构决策不变。

Decision

  • 九条规则的主代码与测试整体暂缓，登记 DEF-008；ADR-0011 的本地优先架构决策不变，仅暂缓其 fail closed 加固部分。①的基础兜底已就位：prepare()/prepareCached() 入口使用单路径段正则（^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$，无路径分隔符、首字符字母数字）拒绝穿越值；符号链接与真实路径边界等完整校验以及②–⑨仍随 DEF-008 暂缓。
  • AgentRuntimeManager 语义降级：prepare() 入口做 agentId 段格式校验（见上条）；快照四要素（agentId.json/systemPrompt.md/skills 目录/可读的 skill.json）齐备即加载，否则重新拉取远程并原地覆盖物化（自愈，不再报"配置漂移"错误）。
  • 远程响应仅保留最小健壮性：querySkillInfo 空结果报错；不再校验 id 匹配、版本坐标、数量/大小上限、重复检测。
  • 物化改为直接写入目标目录（保留逐文件写入），移除临时目录 + 原子移动发布。
  • 设计文档 agent-skill-runtime.md §5.1 同步降级为当前语义，完整九条规则移至本 ADR 附录留档。

Consequences

  • 正面：PR #131 modules 部分缩减约 1100 行；快照中断/损坏自愈（重新物化）而非卡死报错；评审焦点集中在功能本体。
  • 负面（已接受的风险窗口）：
    • 路径穿越①的兜底已就位（入口段格式校验拒绝穿越值），但 agents-root 边界的完整校验（符号链接逃逸等，原①②覆盖范围）仍暂缓；本地 CLI 模式下仅影响用户自己的目录。
    • 无 SKILL.md/references 内容比对：能写缓存目录的进程可持久化注入系统提示词——单用户本地部署威胁模型下风险低，共享目录/跨信任域部署必须恢复③⑤⑥。
    • 无原子发布：物化中断留下部分快照，下次启动自愈重新物化（功能不中断，但多一次远程拉取）。备注：堆叠 PR #138 起 rejectsEmptySkillInfoResult 不再断言失败后目录不残留——直写物化允许半成品残留、由下次自愈覆盖，属接受行为，不再作为测试契约。
    • 无响应形状校验：CampusMate 返回畸形数据可能产生畸形快照（自愈兜底），或版本漂移静默生效。
  • 后续：恢复时从本 ADR 的父提交（138a4fb4）检回 AgentRuntimeManager 及其测试整体还原，逐条对照 DEF-008 清单验收。

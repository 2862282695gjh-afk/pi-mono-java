ADR-0090：补充 Agent 实际取消退出证据

Status: Accepted · Date: 2026-09-08 · Version: 1.0.0

Context

Java 基线 58dd747a 的工具阶段可以在没有新 Assistant ABORTED 消息时取消退出。仅查看最后一条模型消息会遗漏这次中断；直接查看用户停止请求则可能把迟到的取消覆盖到自然完成上。Events v2 要求终态反映真实结局。

Decision

在内部 AgentEndEvent 添加默认 false 的 cancelled，由循环实际退出路径填写。保留既有构造器，false 不输出为 JSON 字段。before hook 返回后先检查取消，再决定是否返回工具失败结果。自然结束不受迟到取消覆盖；Assistant ABORTED 和实际异常仍是独立证据。

Alternatives 与影响

不采用“存在停止请求就判取消”，也不依赖最后一条模型消息猜测工具阶段结局。新增标志是 Java 架构变更，pi 基线 4af9d21d 的 agent_end 没有该字段。该提交不切换 Runtime HTTP，后续协调器再消费证据并持久化权威终态。取消仍是协作式的，不承诺强制杀死任意工具。没有新增依赖、线程或数据库对象。

Validation

代码 8bed9b10 的真实 Agent 循环、当前事件序列化和工具流水线共 47 项测试通过，零失败、零跳过；五组公司镜像按命名空间转换逐字核对。方法长度、格式和图源验证在提交前完成。本机 NativeParent 26.0.0-SNAPSHOT 不可解析，公司编译未验证。

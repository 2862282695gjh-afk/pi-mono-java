ADR-0023 · 删除产品入口前迁移入口无关 Session 能力

Status: Accepted · Date: 2026-08-24 · Design: tool-system-v2

Context

PR 167 的基线提交 f60cc3e78bb8b700527ac082c7c8e10524ede095 删除 CampusClaw CLI/TUI 产品入口。旧包树同时拥有对入口无关的对话压缩、文件追踪和 Slash Command 语义；按包名整体删除会让 Runtime、Cron 和 Child 丢失这些能力。

Decision

选定：以行为职责决定 keep/move/delete，而不是以 TUI/CLI 包名决定删除范围。
  • 阈值压缩、溢出压缩和最多一次重试迁入公共 ManagedAgentSession。
  • 文件追踪迁入压缩核心，活动工具集合下只识别 Read。
  • Slash 核心、Registry 和四个处理器改用宿主无关端口，但首版不向任何 Host 注册。
  • TUI 组件、CLI 启动、JSONL、本机认证、PackageManager、剪贴板和本地 Skill 管理删除。
  • HTTP 仍为 11 个接口；斜杠开头的用户消息不被 Runtime 拦截。

Consequences

方面结果
产品入口仍只有 Spring Boot Runtime 服务，没有 CLI/TUI/RPC/ACP。
Session 语义Runtime、Cron、Child 共享压缩、失败回滚和取消语义。
Slash源码可独立编译测试，但没有 Spring Bean、HTTP 路由或消息解析。
名称/name 的未来适配仍调用 mate-service，不进入 Runtime Session。

Evidence

实现符号：ManagedAgentSession、SessionCompactor、 FileOperationTracker、SlashCommandRegistry、 RuntimeEventProjector、RuntimeSessionModelReconciler。

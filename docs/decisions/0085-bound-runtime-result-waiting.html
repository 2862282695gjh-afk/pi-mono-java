ADR-0085：有界等待固定执行结果

Status: Accepted · Date: 2026-09-08 · Version: 1.0.0

Context

设计仓2ee2a321要求跨实例控制请求等待原执行结果。Java读取基线43a8e000提供固定结果段与真实终态查询， 需要补上请求容量、共享补读和独立响应游标。pi4af9的本地Agent循环没有此跨实例登记机制。

Decision

按实际响应预留容量，按完整执行目标和读取模式共享查询；查询领取附唯一claimId。 同目标等待组被替换后，旧查询不再投递、关闭或释放新组。查询及响应回调在登记锁外执行。

选项与理由

仅按去重目标限制容量会让多个同目标响应绕过上限；仅按组键校验无法隔离迟到查询。 选择响应计数、目标查询合并与领取身份三者组合。周期检查保证兜底，本机提交通知缩短可见延迟且有界。

Consequences

查询数和等待响应资源受控，响应关闭不影响已接受执行。增加登记状态和失败退避，调用方必须在接受前预留、 排好完整回执后绑定，并将实际断连接回释放动作。HTTP接线与流去重由后续集成验收。

无新依赖、凭据持久化、Redis或实例间转发。默认配置和测试限制记录在关联设计。

Validation

回归验证容量、独立游标、查询合并、并发领取、退避与过期结果隔离；精确结果读取沿用ADR0083。

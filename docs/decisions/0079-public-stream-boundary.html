ADR-0079：公共事件流输出边界

Status: Accepted · Date: 2026-09-08 · Version: 1.0.1

Context

设计仓2ee2a321确认Events v2只写SSE data，并且只公开可信提供商摘要。Java基线d9a20777的旧订阅器仍写event/id，thinking事件缺少来源标志。

Decision 与选项

增加独立data-only模式，保留旧入口当前行为；把publicSummary作为AI层的内部来源信息，只有明确reasoning_summary_text.delta能赋予公开标志。旧构造器默认false。后续应用投影层消费标志并构造公共事件。

不依据通用ThinkingContent猜测可公开性，因为不同提供商的内容含义不同。也不立即修改所有生产SSE输出，因为只有完整受理、持久化、结果段和idle关闭全部接入后才满足v2契约。

Mate网关内容为字符串时直接取文本，对象和数组保留JSON文本，缺失或null变为空串；不改变既有凭据及权限处理。

Consequences

正面：后续v2输出可以明确区分摘要与原始思考，实际data字节计数与输出一致；旧字段和容量兼容。代价：AI内部事件增加boolean属性，每轮Responses输出保留一个小型集合；其他提供商需逐个确认安全摘要来源。没有新增Maven依赖。

pi基线5cd93f68的packages/ai/src/api/openai-responses-shared.ts在完成时还允许item.content回退；本项目不把该内核内容自动作为公开摘要。此差异属于CampusClaw安全加固，data-only为产品HTTP契约变化。

Validation

真实SseEventBuilder与Jackson检查协议片段、心跳、字节计数和旧字段；MockWebServer覆盖摘要流与无摘要的reasoning结束事件。集成复验共85个测试通过（AI 41、SSE 9、Mate 35），另检查AST方法长度、格式和镜像。Mate质量脚本的6项既有异常/辅助断言提示经过人工复核，实际断言存在。企业NativeParent本地不可解析，企业编译未验证。本片不代表生产v2端到端接口已经切换。

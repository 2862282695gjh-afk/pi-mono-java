ADR-0044：校验受管 Agent 根路径包含关系

StatusAccepted
Date2026-09-03
Source baselineorigin/main@c9d858bc8261bf07f5585f545b53495bf2226a56
Observed sourcemodules/coding-agent-cli/src/main/java/com/campusclaw/codingagent/runtime/AgentRuntimeManager.java，符号 requireAgentRoot；modules/coding-agent-cli/src/main/java/com/campusclaw/codingagent/common/identifier/ResourceIdentifierPatterns.java，符号 AGENT_ID_PATTERN
ClassificationSecurity hardening

Context

分析基线中，AgentRuntimeManager#requireAgentRoot 先要求 agentId 符合 agent- 加 32 位十六进制字符的领域格式，再调用 agentsRoot.resolve(agentId).normalize() 生成缓存目录。该格式不接受路径分隔符、.. 或绝对路径，因此当前标准文件系统调用不能由普通请求构造目录逃逸。

路径拼接完成后没有独立验证结果仍位于规范化的 agentsRoot 下。安全边界因此隐式依赖 ID 正则，静态分析也无法从路径操作本身确认包含关系。未来正则、配置绑定或文件系统提供者变化时，缺少后置校验会扩大回归风险。

Decision drivers

  • 让每个动态路径拼接点自身具备可审计的根目录包含性保证。
  • 保留现有领域 ID 校验，不降低对非法输入的拒绝强度。
  • 在任何文件读取、目录创建或远端访问前失败。
  • 不改变合法 Agent 的磁盘布局与缓存、refresh 或发布行为。

Considered options

只依赖 Agent ID 正则

优点：不增加代码。
缺点：路径安全与领域格式规则耦合，拼接结果没有独立、显式且 fail-closed 的验证。拒绝。

仅检查字符串前缀

优点：实现直观。
缺点：字符串前缀会把相邻目录名误判为子目录，例如 /agent-other 可匹配 /agent，并且绕过文件系统路径段语义。拒绝。

规范化 Path 后使用 startsWith 校验

优点：按文件系统路径段判断包含关系，直接保护 resolve 的结果，并与现有格式校验形成双层边界。
缺点：在当前严格 ID 正则下属于冗余校验，但该冗余是有意的纵深防御。接受。

Decision

  • 先把配置的 agentsRoot 转为绝对路径并规范化。
  • 以规范化根目录执行 resolve(agentId) 并再次规范化。
  • 要求结果 startsWith 规范化根目录；失败时抛出 IllegalArgumentException。
  • 保留 AGENT_ID_PATTERN 前置校验，使非法领域 ID 在路径操作前被拒绝。
  • 增加独立回归测试，模拟路径解析结果位于配置根目录之外，证明后置校验会阻止后续访问。

Intentional difference

安全加固：合法 Agent 的行为与目录布局不变；新增行为只在规范化结果不属于配置根目录时 fail closed。该校验不是对 pi 既有行为的描述，而是 CampusClaw Java 实现新增的路径边界保证。

Consequences

  • 正面：动态路径拼接点可以独立证明不会逃逸 agentsRoot。
  • 正面：将来即使 ID 规则被放宽，路径包含性仍有独立保护。
  • 兼容性：所有当前合法 agentId 继续解析为原目录。
  • 失败语义：包含性验证失败时，在文件系统或 Mate 产生副作用前抛出参数异常。

Validation

  • 执行 AgentRuntimeManagerTest，覆盖非法 ID 与规范化结果逃逸两种拒绝路径。
  • 执行格式、Checkstyle、模块测试、镜像同步与 Git diff 检查。
  • 验证设计文档不含 Mermaid、PlantUML 为 ASCII、SVG 与源码链接有效。

Context

公司父 POM 会向 mate-campusclaw 传递引入 Actuator；父 POM 源码和最终公司 Classpath 不在本仓库，这一条件来自外部集成环境。变更前的公司专用配置已经默认禁用 Endpoint，并维护 30 项 Actuator 自动配置排除，但没有设置负数管理端口，也没有排除通用及 Servlet 管理上下文自动配置。

本次目标是补齐管理 Web 面的关闭边界。现有排除项承载了历史公司兼容约束，在缺少公司父 POM 的情况下不能证明删除它们安全，因此不得用更短的 3 项清单替换。

Decision drivers

  • 不恢复任何现有被排除的 Actuator 自动配置。
  • 显式关闭独立管理服务器及管理 Web 上下文。
  • 保留业务 server.port 和 HTTP/SSE 路由。
  • 把公司环境差异限定在手工维护的镜像配置。

Considered options

用 3 项管理 Web 排除替换原清单

优点：配置明显更短。
缺点：会恢复健康检查、指标、审计、缓存等 29 项原有排除，扩大变更范围且无法在当前仓库验证公司兼容性。拒绝。

只增加 management.server.port=-1

优点：改动最少。
缺点：没有显式隔离通用和 Servlet 管理上下文自动配置，未完整落实给定配置。拒绝。

保留原清单并追加缺失项

优点：不放宽现有兼容边界，同时补齐管理端口和管理上下文保护。
缺点：长排除清单继续存在，后续升级 Spring Boot 时仍需维护。接受。

Decision

  • 在公司专用 application.properties 增加 management.server.port=-1。
  • 保留 management.endpoints.enabled-by-default=false 和全部原有排除项。
  • 保留已有的 WebEndpointAutoConfiguration，不重复声明。
  • 在原列表末尾追加 ManagementContextAutoConfiguration 与 ServletManagementContextAutoConfiguration。
  • 新增公司镜像专用测试，加载真实配置并验证上述关键项；同步脚本必须保留该测试。

Intentional difference

公司集成约束：通用模块不应用这些 Actuator 属性，只有公司镜像针对父 POM 传递依赖关闭管理面。安全加固：管理 HTTP 服务和管理 Web 上下文被显式关闭。架构边界：业务 Servlet Web 服务继续使用 server.* 配置。

Consequences

  • 正面：不会因本次修改恢复任何历史上已排除的 Actuator 组件。
  • 正面：管理端口和两类管理上下文都有明确关闭配置。
  • 负面：自动配置排除清单仍较长，Spring Boot 升级时需要检查类名变化。
  • 边界：本仓测试验证配置加载；公司父 POM 下的最终启动仍需公司工程验证。
  • 边界：本决策不改变 Log4j2 统一运行时，也不新增 Windows 支持承诺。

Validation

  • 配置加载测试断言管理端口为 -1、Endpoint 默认禁用，并包含 3 个关键管理 Web 排除项。
  • 执行 mate-campusclaw 完整 Maven verify。
  • 执行镜像同步 dry-run，确认公司专用配置和测试不会被覆盖或删除。
  • 检查可执行 JAR 内的配置，并执行 Git 与文档静态校验。

ADR-0076：Session Events v2 联合请求边界

Status: Accepted · Date: 2026-09-08 · Version: 1.0.0

Context

设计仓 2ee2a3211da68ad87b0d9cab353e691b00bdaebd 已确认同一 POST 接收 user.message、user.interrupt 或 user.tool_confirmation。 Java 基线 fd556dce3cfa12e5e834b6e9b8f835f10e7d67c8 的生产入口仍使用扁平 UserEventRequestVO，无法精确表达三类字段和有序内容块。

Decision 与选项

  • 采用只有 event 的顶层 RequestVO、封闭的三事件联合类型和封闭的文本/文件内容块联合类型。
  • 先用无状态 Jackson 解析器校验对象、准确 type、未知字段和显式 null，再由 Jakarta Validator 校验长度、格式、顺序和条件字段。
  • 状态相关校验留在事务应用服务：VO 不查询 Session、执行目标或待确认工具，也不设置请求默认值。
  • 不采用松散 Map 后置识别，因为未知或错配字段可能越过 Controller 边界；不在本片切生产 Controller，因为完整响应和三类 Handler 尚需一起启用。

Consequences

正面：每个 Handler 收到准确 RequestVO，结构错误在持久化前失败，未知字段不会被宽松忽略。 代价：解析会暂存一个与请求大小同阶的 JSON 树，并增加专用 VO 与解析器类型。 本片不改变现有 HTTP 行为；后续必须与完整公共事件、data-only SSE、idle 关闭及控制事务一起切换。

pi 5cd93f688aaab89dbb6dfa4aca535f21796ae185 的 packages/coding-agent/src/core/agent-session.ts#prompt 只提供文本执行入口； 结构化 HTTP 联合请求属于 CampusClaw 产品约束与安全加固。没有新增 Maven 依赖、表、线程或凭据存储。

Validation

真实 Jackson 与 Jakarta Validator 的 17 项聚焦测试覆盖三类选择、显式 null、未知字段、 内容块、UTF-16 长度、文件规则与确认条件；Checkstyle 0 违规，测试质量检查 0 错误、0 警告。 生产 Controller 尚未切换，因此这些测试不表示 v2 HTTP 已完成。

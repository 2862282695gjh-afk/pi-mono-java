ADR-0067：实际运行快照上的 Skill 准入

Status：Accepted · Date：2026-09-07 · Version：1.0.0

Context

实现基线 b7f077d59b09362dc366241920a85b6d218d1189 已有公共 Session 工厂准入接点， Runtime 注册表却固定传 null。显式 Skill 的名称和直接绑定需要在本次实际 Agent 快照上检查， 不能把展示清单当作执行授权。本片不依赖未合入的 Builtin 应用代码。

本片新增 runtimeapi/command/skill/SkillCommandAdmission.java 与 Registry validator 重载的 代码证据为 a143a00798a319e1404f393e4b50fea02de53eb2，不归入起始基线的已有行为。

源码根为 modules/coding-agent-cli/src/main/java/com/campusclaw/codingagent/： session/AgentSessionFactory.java:create 在 prepare 后先执行 validator； session/ManagedAgentSessionRequest.java 已定义该 Consumer； runtimeapi/runtime/RuntimeSessionEngineRegistry.java:register/createSession 已负责容量和失败释放； runtime/PreparedAgentRuntime.java:findSkill 能从完整快照精确查找直接绑定。

设计仓只读基线 88f4df16bc24bbfcd28e1ec374feb2de0db8be3b，Skill 3.2.0 §3–4 要求共享严格名称、绑定复核，不要求额外私有 Skill 调用快照。pi 4af9d21d3b4d664e4a29fcabfec85171077248e3 的 packages/coding-agent/src/core/agent-session.ts:_expandSkillCommand 是本地展开及未知名称回退， 不作为 Java HTTP 或正文公开的授权。

考虑过的选项及取舍

  • 仅检查先前的命令清单：改动小，但不能证明实际执行对象的绑定，拒绝。
  • 新建 Skill 专属 Session/容量/事件通道：隔离方便，但复制生命周期和失败处理，拒绝。
  • 贯通现有 runtimeValidator：接点清晰、复用实际快照和失败清理，仅增加窄准入策略，采用。

Decision 与理由

  • SkillCommandAdmission 是单次调用的不可变策略，仅持有目标 Agent ID 与无前缀 Skill 名称。
  • 名称复用 ClawConstants.Skill.isValidName，不增加第二套正则；精确直接绑定缺失返回 COMMAND_NOT_FOUND。
  • 实际快照缺失、身份不一致或禁用返回 AGENT_NOT_AVAILABLE；不会回退为普通消息执行。
  • Registry 的兼容重载透传 Consumer；既有七参数入口保持无 Skill 检查，容量与 Holder 清理不另建系统。
  • 复用接点属于 Java 架构变更；严格名称和拒绝未知显式调用属于已确认产品约束与安全加固。

Consequences

  • 正面：后续入口能核对真实执行快照；不重新读 Skill 文件，不增加远程请求、锁或依赖。
  • 代价：完整 Skill 调用仍需后续输入准备和应用集成；本片没有 submitSkill、HTTP 路由或伪 Handler。
  • 边界：快照不是 Session 全生命周期版本绑定；测试替换输入只证明准入接点，不承诺热刷新。
  • 后续：Skill SSE 已确认，但展开正文进入普通 message 会同时进入 SSE/GET 历史，正文呈现策略需精确确认。 本片不决定公开正文，也不创建额外私有快照；不得只展开执行用 UserMessage、却保存另一 message。 这不涉及既有 System Prompt 装配，本片不定义其与 Skill 正文的组合策略。
  • 无 SQL、升级脚本、公共历史类型、通用 commandId 或设计仓改动。

验证

17 个名称与绑定用例、3 个真实工厂/注册表集成用例，验证失败不装工具、不留 Holder、容量释放及普通登记兼容。 原有 Events 和注册表测试回归。完整模块、镜像、Java AST、格式、文档渲染与新增行数门禁结果见 PR。 这些测试不证明尚未实现的跨进程 Skill HTTP 或正文恢复；公司 NativeParent 不可用时镜像编译仍未验证。

ADR-0094：提交执行终态后释放资源

Status: Accepted · Date: 2026-09-08 · Version: 1.0.0

Context

已接纳执行的模型结束与数据库提交可能分别失败；中断被接纳也不代表 Agent 实际因中断退出。

Decision

实现 ba9e497c 按实际 STOP/ERROR/ABORTED 形成 done/failed/terminated。以固定目标提交内部和公共 idle 后释放 Holder。失败时取消监听和超时、关闭输出，保留原执行对象、凭据与固定终态计划；独立线程重试同一 ID 和时间，不重跑模型。

Alternatives 与理由

先释放会失去重试对象并误报容量可用，重跑模型可能重复副作用。选择保留执行至终态提交，代价是数据库故障期间仍占用容量。pi4af9d21的Agent循环不提供数据库终态事务，这属于Java架构变化。

Consequences

增加一个延迟调度线程，支持运行时故障恢复；不新增依赖、表或升级流程。HTTP由后续服务接入并删除旧开发实现。

Validation

root协调器11项及轮询7项测试通过，配置合并格式修正后Spotless/Checkstyle通过。固定Clock及可控任务验证同一终态重试和资源释放。企业NativeParent不可解析，公司编译未验证。

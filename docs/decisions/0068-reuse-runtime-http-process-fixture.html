ADR-0068：复用 Runtime HTTP 跨进程测试夹具

Status：Accepted · Date：2026-09-07 · Version：1.0.0

Context

Java 基线 b7f077d59b09362dc366241920a85b6d218d1189 的 modules/coding-agent-cli/src/test/java/com/campusclaw/codingagent/runtimeapi/web/RuntimeHttpProcessOpenGaussIT.java 把进程、协议桩、HTTP 与断言放在一个 694 行类里。旧 prepareRuntimeFiles 缺少完整受管目录， 本地 customModels 和 /v1/chat/completions 也已不是主干真实 Mate 模型入口。

当前行为证据：runtime/AgentRuntimeManager.java:prepareCached/loadSnapshot、 runtimeapi/model/MateRuntimeModelManager.java:resolveModel，相对 coding-agent-cli Java 包根； modules/ai/src/main/java/com/campusclaw/ai/provider/mate/MateServiceModelManagerProvider.java:eventFlux。 完整路径、断言依据和图见实现说明。本方案是 Java 测试架构调整，不以 pi 为夹具基线。

新增源码单独绑定实现提交 0a2c00b945f43bea7528875f1503bb662e2e3b56： RuntimeHttpProcessFixture.prepareRuntimeFiles/startRuntime/ModelStub.close、 RuntimeHttpProcessFixtureTest 和 RuntimeHttpProcessOpenGaussIT.testPackagedJarRestartsWithPersistedHistory； 三者位于上述测试包，不能当作 b7f077d5 已存在的符号。

考虑过的选项与取舍

  • 在每个 Commands 场景复制旧 IT：短期方便，但重复行数高且继承过期入口，拒绝。
  • 只用 MockMvc 或替换生产 Bean：快速，但无法证明打包启动、真实网络与数据库恢复，拒绝。
  • 新增通用测试服务或公开调试接口：扩展范围和产品风险，不需要，拒绝。
  • 提取当前用到的包级夹具，同时让旧场景消费：可复用并有真实验收约束，采用。

Decision 与理由

  • 共享完整 Agent/Skill 缓存、JAR 启动、HTTP 帮助方法与模型 gate；消费者保留领域断言。
  • 使用当前 campusmate.base-url 和 Mate Chat 路径；其他路径返回 404，禁止模型桩掩盖 Manager 缓存缺陷。
  • 测试显式提供专用数据库；移除无必要的全表 TRUNCATE，所有读取按本次 Session ID 隔离。
  • 修复提取触达的资源所有权：计数原子化、exchange finally 关闭、executor 中断与关闭。
  • 加入真实重启场景，验证同一 Session/ETag/历史和下一轮模型实际输入，不只是再次启动成功。

Consequences

  • 正面：后续 Commands 验收可复用真实环境，当前 Events 继续证明 SSE、控制队列、配置和恢复。
  • 代价：真实 IT 仍需本地 JDK、打包 JAR 和预先安装表的专用 openGauss；普通单测不能替代它。
  • 边界：不增加生产路由、公开字段、Entry 类型、SQL 或依赖，不实现 Skill 调用或 Commands HTTP。
  • 未修改设计仓、未使用未合入应用代码；各实现独立开发，依赖合入后再串行集成。

验证

夹具单元验证真实 prepareCached、Skill 摘要可见性、HTTP gate 和资源关闭；两个真实 IT 验证原 Events 场景与进程重启。公司镜像编译依赖 NativeParent，无法解析时显式保留未验证限制。

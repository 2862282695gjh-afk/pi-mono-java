ADR-0107：开发代理设置 secure=false

状态：Accepted。日期：2026-09-10。分类：本地联调产品约束。

Context

用户要求在 frontend/vite.config.ts 设置 secure: false。源码基线 33c3951ddecb8585881c8ec75265c6aa63145e83 的 server.proxy['/campusclaw-service'] 仅设置 target 和 changeOrigin。

Options

保留证书校验并配置受信任 CA 可以验证上游身份，但需要维护本地证书配置；显式 secure=false 便于连接联调 HTTPS 后端，但跳过此代理的上游证书验证。按用户指定采用后者。

Decision

在现有 /campusclaw-service 代理中增加 secure=false，保留目标地址与 changeOrigin。此选项仅属于 Vite 开发代理；认证助手的独立 HTTPS 请求继续校验证书。

Consequences

开发代理可以连接未被本机信任的 HTTPS 后端；该代理不再验证上游证书。没有新增依赖、公共接口或组件结构变化，现有协调图保持不变。

Validation

通过 Vite resolveConfig 检查生效选项，并执行类型检查、生产构建、Spotless 和差异检查；不以配置检查代替真实 HTTPS 后端联调。

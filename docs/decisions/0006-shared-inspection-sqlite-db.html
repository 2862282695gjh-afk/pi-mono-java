ADR-0006 · device-inspection-re 写库、campus-device-ops 只读同一 SQLite

Status: Accepted · Date: 2026-06-10 · 设计文档: openclaw-device-skills

Context

园区演示需要「巡检写入 → 运维查询/推送/工单」两段 Agent 能力。若各 skill 维护独立 DB，runId 与告警会分叉，OpenClaw 上无法连贯演示。

Decision

  • 唯一写入方：device-inspection-re/scripts/judge_rules_re.py → device_inspection_re.db
  • 读取方：campus-device-ops 脚本通过 CAMPUS_OPS_DB_PATH / 默认路径读同一文件
  • Schema 变更只在写方执行；读方禁止 ALTER TABLE
  • 种子 fixtures（registry、assignees、device JSON）随 skill 入库；*.db、工单、outbox 不入库

Consequences

  • Fresh clone 可跑 mock API + 种子数据；首次巡检前需有 rules_re.json
  • 并发写仍受 SQLite 限制；生产应换 PostgreSQL（见 templates/schema.sql）

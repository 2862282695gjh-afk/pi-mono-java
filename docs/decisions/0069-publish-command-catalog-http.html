ADR-0069：独立发布共享命令清单 GET

Status：Accepted · Date：2026-09-07 · Version：1.0.1

背景

主线 7d771ca802b781361e0e62e9014bafb6b0ed5e7a 已具备完整 Catalog 应用能力， 尚未发布命令清单 HTTP。设计仓只读基线 88f4df16bc24bbfcd28e1ec374feb2de0db8be3b 的操作 12 和 Slash Command 1.6.0 定义共享的 Builtin/Skill 轻量清单。开发协调已明确授权 GET 独立交付，不等待 POST 或 Skill 正文公开策略；这仅改变交付顺序，不修改设计仓。

本片实现证据为 afee9bd333d0fc74ba0cef8b27b6df7357acdf30。 源码根 modules/coding-agent-cli/src/main/java/com/campusclaw/codingagent/ 下， 新增 runtimeapi/web/RuntimeCommandCatalogController.java#list，修改 runtimeapi/web/RuntimeExceptionHandler.java#response；既有 runtimeapi/service/command/CommandCatalogService.java#list 负责一次缓存解析与响应组装。

F245-C1 修复证据为 ce03d9e1d92ab2e8b5711caca4df728625ce89d8， 已正常合入主线 0ed71babf3f4c0a1d6260f4101f702bb88e822ca；仅修两种语言的集中资源与路由断言。

pi 5cd93f688aaab89dbb6dfa4aca535f21796ae185 的 packages/coding-agent/src/core/slash-commands.ts:BuiltinSlashCommand 只提供本地命令提示。 Java HTTP、完整缓存与操作级错误投影是产品约束和架构接入，不是 pi 的已有协议。

选择与理由

  • 采用独立只读 Controller，依赖既有应用 Service 与 ResultBeanAdapter；不复制 Source 读取、状态过滤或 DTO 组装。
  • 拒绝在 Controller 只返回 Builtin 的简化列表：它会掩盖完整缓存缺失，与共享发现契约不符。
  • 清单缺完整缓存必须为 503 且 Retry-After 为 3；集中错误处理器按实际 HandlerMethod 识别此操作。 拒绝全局将 AGENT_NOT_AVAILABLE 从 422 改成 503，因为既有创建 Session 等操作仍要求 422。
  • 沿用共享 ID 常量、Jakarta 标量参数校验与语言协商；集中错误资源必须遵循 chat-http-v1-design.md §5 第 595–601 行明确冻结的消息。 INVALID_SESSION_ID 使用“sessionId 格式不正确。”及“The sessionId format is invalid.”； 不能把这项正文规定当作任意示例差异。AGENT_NOT_AVAILABLE 既有集中消息与冻结表一致，保持不变。
  • GET 与 POST 分开交付，满足小 PR 限制；不安装伪 Skill Handler，也不通过普通消息回退模拟执行成功。

影响与边界

新增普通 JSON 读取入口。idle 返回固定顺序七个 Builtin 和名称排序的 Skill；running 移除 compact/Skill， 并去掉 model/thinking 输入提示。完整空绑定可成功，缺缓存整体失败。返回值不暴露 Skill ID、版本、路径或正文。

Spring 单例无请求状态；GET 不占容量、刷新 Agent、读取执行凭据或追加 Entry。清单读取的状态不是后续执行授权。 不新增 SQL、升级脚本、依赖、认证器、POST 路由或事件类型；保留旧未注册命令原型，删除另行交付。

验证

修复后有 19 个新 MVC 用例，通过实际响应验证中英文冻结文案及既有清单契约； 含原有路由、消息源、语言、错误码及已合入测试辅助代码，共 59 项定向测试通过。 初始 afee9bd3 的完整 verify 为 1860 项，0 失败、错误或跳过；本次文字修正未在本地重跑全量。 新增代码模块侧 503 行、镜像后 1006 行；整个 PR 继续执行新增行数门禁。

公司镜像同步完成，但 NativeParent 不可用，不能宣称其独立编译通过。本片没有新增 GET 的真实 JAR/openGauss 测试， 不把 MVC 测试当作跨进程验证。图生成、链接及桌面/窄屏渲染的最终证据见 PR。

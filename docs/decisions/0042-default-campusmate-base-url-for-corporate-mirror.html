ADR-0042：为公司镜像设置 CampusMate 本地缺省地址

StatusAccepted
Date2026-09-01
Source baselineorigin/main@2cb1661fd4dc27f2bc02579c44878d7a69775c3d
Observed sourcecampusclaw/src/main/resources/application.properties、modules/coding-agent-cli/src/main/resources/application.yml、campusclaw/src/test/java/com/huawei/hicampus/claw/codingagent/config/ManagementConfigurationTest.java

Context

变更前，公司镜像与通用主模块都使用必填占位符 ${CAMPUSMATE_BASE_URL}。公司镜像的 本地集成环境已约定 CampusMate 在本机 8591 端口通过 HTTPS 提供服务；每次都额外注入同一个地址 增加部署配置成本。通用主模块面向多种部署环境，不应继承该公司环境假设。

公司镜像的 application.properties 与 ManagementConfigurationTest 均为镜像侧手工维护文件，不由主模块同步覆盖，因此可以在 不改变规范源码配置的前提下锁定该产品差异。

Observed behavior

  • campusclaw/src/main/resources/application.properties 声明 campusmate.base-url=${CAMPUSMATE_BASE_URL}，缺少环境变量时没有地址。
  • modules/coding-agent-cli/src/main/resources/application.yml 使用相同的必填环境变量占位符。
  • ManagementConfigurationTest 只校验公司管理端口和 Actuator 暴露范围，未锁定 CampusMate 地址。

Decision drivers

  • 让公司镜像在标准本地集成拓扑中无需额外地址配置即可启动。
  • 保留生产和非标准环境通过 CAMPUSMATE_BASE_URL 覆盖地址的能力。
  • 不把公司环境假设扩散到通用主模块。
  • 不恢复旧部署变量、转换脚本或应用配置别名。

Considered options

继续要求所有环境显式配置

优点：没有新的缺省行为。
缺点：公司镜像的标准本地拓扑仍需重复配置固定地址。拒绝。

通用主模块和公司镜像同时增加缺省值

优点：两个配置文件表面一致。
缺点：把公司本地部署假设扩散到通用产品，可能让配置遗漏静默连接本机。拒绝。

只为公司镜像增加缺省值

优点：满足公司集成拓扑，并保持通用配置严格。
缺点：镜像与规范配置存在有意差异，需要专有测试和文档维护。接受。

Decision

  • 公司镜像声明 campusmate.base-url=${CAMPUSMATE_BASE_URL:https://localhost:8591}。
  • 显式 CAMPUSMATE_BASE_URL 优先于缺省值，并继续经过现有共享 URI 校验。
  • 通用主模块继续声明 base-url: ${CAMPUSMATE_BASE_URL}，环境变量保持必填。
  • 公司专有测试分别覆盖未设置环境变量时的缺省值和显式覆盖行为。
  • 不修改 CampusMate HTTP/SSE、认证、数据库、Mate Tool 或其余配置契约。

Intentional difference

公司集成产品约束：只有公司镜像知道本机 HTTPS 8591 端口这一标准拓扑。 非架构变化：共享客户端、Endpoint 目录、URI 校验和主模块同步关系保持不变。

Consequences

  • 正面：标准公司本地环境不再需要重复设置固定的 CampusMate 地址。
  • 正面：部署仍可使用环境变量指向远端或不同端口。
  • 约束：本机服务未启动或 TLS 证书不可用时，实际请求会以连接或证书错误失败，不回退到其他地址。
  • 维护成本：镜像专有测试必须防止同步流程覆盖，并与手工 properties 一起审查。

Validation

  • ManagementConfigurationTest 验证无环境变量时得到 https://localhost:8591。
  • 同一测试验证显式 CAMPUSMATE_BASE_URL 覆盖缺省值。
  • 同步 dry-run 验证公司专有测试和手工配置不产生镜像漂移。
  • 公司 Maven 环境执行镜像测试；普通环境若无法解析 NativeParent，必须明确报告该门禁未运行。

ADR-0102：Claw Runtime Events v2 前端迁移

状态：Accepted，前端实现；真实后端联调待完成。日期：2026-09-08。

Context

用户确认后端会话开发 Claw Runtime，本任务仅交付前端。初始源码基线 821418e7f2ece298a04a066ab8d11d3388ef2f16，同步 9b01a9f1e659359b6a7bff9ec622e6700ef6e384。目标协议来自设计仓 9b8c5b7 的 Events B01～B15 与 Slash 1.3.0。证据见功能设计的路径/符号表。

Options

保留旧入口并自动兼容：无法可靠区分接受与执行终态，拒绝。改成公共 Mate：超出本次用户范围且桥接未完成，拒绝。内部工作台严格消费新契约，使用隔离 fixture 与后端并行联调：接受。

Decision

  • 用 eventId / sourceEventId、data-only SSE 和数字历史页替换旧 wire；同文历史不能确认丢失回执。控制统一用三种 user.*，删除队列与旧停止入口。
  • 完整事件与预览共享 Store。Session 与 ETag 原子应用，Models 不覆盖资源版本，412 只读取、不自动重写。
  • 命令使用独立草稿及不可变调用快照，二次确认执行；Builtin 临时结果和 Skill SSE 分离。
  • 公开思考摘要与工具文本按文字显示，Assistant 保留安全 Markdown。保留暖灰样式和独立活动框，命令不加装饰图标。
  • 保持内部受控工作台定位，上传与公共 Mate 接入不开启，不修改后端。

Consequences

安全加固：拒绝旧 wire、未知形状与自动写重试；响应读取中止不被误报为业务停止。产品约束：不再提供运行中队列和调整方向。架构变化：共享事件 Store、命令调用快照和独立临时结果；代价是旧服务不再兼容，必须等待 v2 HTTP 接线。

Supersedes in part

ADR-0020 的旧控制与同文确认；ADR-0030 的原始 thinking wire 和活动 Markdown；ADR-0031 的截断参数呈现。内部部署限制、O1 品牌、Assistant 安全渲染和整轮复制继续有效。

Validation

运行 Vitest、类型检查、构建、依赖审计、浏览器契约 fixture 与 PlantUML 验证；不声称 Java 后端真实 E2E 或上传通过。

ADR-0056：落实 Skill 原始名称与目录身份约束

Status：Accepted（落实已确认约束，不新增产品设计）
Date：2026-09-07
文档版本：1.0.0

Context 与源码证据

Java 复核基线：7b3769a5eabe2d131af3023631d7ad24e6d9a9e1。 以下路径相对 modules/coding-agent-cli/src/main/java/com/campusclaw/codingagent/： skill/SkillLoader.java:parseSkillFile 缺少 name 时回退目录名，已有值用 String.valueOf 转换且未比较父目录。validateName 已调用共享严格规则， 但字符合法不能证明原始类型或目录身份合法。

runtime/AgentRuntimeManager.java:writeSkills/loadSkill/requireSessionLoadable 通过同一 Loader 验证发布与缓存；runtimeapi/agent/RuntimeAgentPromptLoader.java:loadSkill 直接消费 Loader；runtimeapi/service/command/SkillCommandSource.java:list 通过 prepareCached 间接消费。只改受管发布入口会遗漏共享加载与缓存入口。

设计依据为 pi-mono-java-design@fd8604956632c880264434791465d1f59917038d 的 04-命令与技能/02-技能命令/README.md §3 和通用模块 §3.1：name 必须是原始非空 String，与目录及绑定逐字符一致，禁止回退、转换、裁剪和自动改名。本次只改实现仓。

pi 对照 4af9d21d3b4d664e4a29fcabfec85171077248e3 的 packages/coding-agent/src/core/skills.ts:validateName/loadSkillFromFile 对缺少名称回退目录，名称错误只产生 warning，描述有效时仍加载。 Java 拒绝该容忍行为，分类为已确认的产品约束与安全加固，不声称是 pi 现状。

Decision

  1. 共享 Loader 首先要求原始名称是 String，再执行现有非空、长度和严格正则检查，最后比较目录名。
  2. 复用 ClawConstants.Skill，不新增 Validator、别名、正则或策略开关。 绑定元数据一致性继续由受管 Manager 检查，不放入 DTO。
  3. 单文件失败抛 SkillLoadException；批量扫描和提示词略过非法项；不改变异常翻译、锁与原子发布流程。
  4. 更新旧回退成功测试和跨消费者回归。合法的带引号字符串 null、true、123 仍允许，不能把类型检查变成关键字禁用。

选项、取舍与所选理由

  • 保留回退或自动修正：减少上游修正成本，但违反已确认规则且改变资源身份，拒绝。
  • 仅在 Command 或发布入口拦截：局部改动少，但共享加载与缓存仍可能放行，拒绝。
  • 在共享 Loader 拒绝：所有真实消费者复用既有错误路径，且不复制规则，选择。

Consequences

正面：加载、提示词和命令发现不再接受缺省或强制转换名称；非法刷新不替换旧完整目录。 代价：来源方必须提供合法显式名称；非法缓存不再命中，prepare 可能触发既有的重新拉取。 不新增存储、网络入口、数据库或线程，不改变合法名称和领域 ID 格式。

后续：Builtin、Skill 与共享 HTTP 由用户统一实施；Skill 真实执行仍需专门切片， 不把发现回归视为执行验收。本次不推进 Compact 6b，不引入 Events V2 候选迁移。

验证边界

SkillNameContractTest 用相同样例验证单文件、批量、提示词、发布、刷新保留、重启缓存与命令发现； 覆盖缺少/null/非字符串、目录不一致、空白/换行、非法字符/连字符、1/64/65 字符。 旧实现上 61 项中 12 项失败，证明旧绿色回归未覆盖这些契约。 本次构建、质量、镜像、行数及图形验证结果随修复 Draft PR 记录，不沿用旧 PR 的通过数量。

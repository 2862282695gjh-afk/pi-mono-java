ADR-0016 · 显式维护 en-US 与 zh-CN 国际化资源包

Status: Accepted · Date: 2026-08-20 · 设计文档: coding-agent-cli · 基线: origin/main@3a6358bc9dd5837cdf5ac866fc0761298372510a

Context

分析基线在 classpath 根目录维护英文基础资源 messages.properties 和简体中文资源 messages_zh_CN.properties，并依赖 Spring Boot 默认 MessageSource 自动配置。英文 Locale 因而隐式复用基础资源包，资源路径也没有独立的国际化目录。目标设计要求显式表达两个受支持 Locale，且不保留基础 messages.properties。

该决策只改变 CampusClaw Runtime 的内部消息资源布局和加载方式。HTTP 状态、稳定错误码、ResultBean 结构和 SSE 事件结构保持不变。

Options considered

  • 保留 messages.properties 与 messages_zh_CN.properties
    Pro：继续使用 Spring Boot 默认自动配置，没有自定义 Bean。
    Con：英文 Locale 依赖未标注 Locale 的基础资源，不能满足显式英文文件要求。Rejected。
  • 同时维护 messages.properties、messages_en_US.properties 和 messages_zh_CN.properties
    Pro：保留自动配置并显式声明英文 Locale。
    Con：基础资源和英文资源重复，增加 key 与文案漂移风险。Rejected。
  • 仅在 i18n 目录维护 messages_en_US.properties 和 messages_zh_CN.properties
    Pro：支持的 Locale 和目录边界显式，不存在英文双份资源。
    Con：不能依赖 Spring Boot 默认消息源自动配置，必须显式注册 MessageSource，并通过测试阻止双资源 key 漂移。Chosen。

选择理由：显式 Locale 资源比隐式基础资源更符合本项目的可读性要求；自定义消息源的固定配置成本可控，并可通过上下文启动和资源完整性测试锁定。

Decision

  • 主模块只维护 src/main/resources/i18n/messages_en_US.properties 与 src/main/resources/i18n/messages_zh_CN.properties；不创建 messages.properties。
  • mate-campusclaw 镜像保持相同的 src/main/resources/i18n/ 相对路径，由现有镜像同步流程生成。
  • Runtime 显式注册名称为 messageSource 的 ResourceBundleMessageSource，basename 为 i18n/messages，编码为 UTF-8，默认 Locale 为 Locale.US，并关闭系统 Locale 回退。
  • 只支持 en-US 与 zh-CN；按 Accept-Language 的语言范围和 q 权重协商，缺失、非法或不支持时回退 en-US。
  • Java 错误枚举名称、resCode 和消息 key 保持一致；两个 Locale 文件必须具有相同 key 集，并覆盖全部 RuntimeErrorCode。
  • 错误 HTTP 响应和 SSE stream.error 的 resMsg 国际化；成功 ResultBean 继续固定返回 resCode="0"、resMsg="success"。

Consequences

  • 正面：受支持 Locale、资源位置、默认语言和回退规则均显式；英文文案没有基础资源副本。
  • 负面：Runtime 必须维护自定义 MessageSource；删除基础资源后，遗漏 Bean 配置会导致消息解析失败。
  • 兼容：公共响应结构、错误码和状态码不变；仅资源加载位置与语言协商实现需要迁移。
  • 验证：发布前必须验证无基础资源包时应用上下文启动、双资源 key 相等、错误枚举覆盖、语言权重、英文回退以及 HTTP/SSE 中文错误。
  • 数据：无数据库表、字段或数据迁移。
